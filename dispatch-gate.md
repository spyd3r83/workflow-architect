# Dispatch Gate

Coordinator dispatch requires task(), an assigned agent, and an explicit immutable run/session binding. Assigned task:false leaves execute scoped work and return delegation needs. There is no alternate delegation primitive or coordinator self-certification of specialist work.

Typed durable effects bind call, origin, phase attempt, authority, child sessions and deliverable digest. Successful receipts require authenticated host evidence and terminal registered children. A failure is not a passed gate. Unknown or active-child cancellation keeps effects protected. Explicit reconciliation consumes a caller-supplied current CAS tuple and preserves original identity.

Network packages retain their own specialist map and completed-receipt checks in network_policy.py; shared runtime refresh does not replace that module or phase configuration. See `run-binding.md` for supported host contracts and unsupported provider boundaries.
